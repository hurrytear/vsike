# Project notes

## Publishing

- This repository is the source for `https://www.vsike.com`.
- Push the intended changes to `github.com:hurrytear/vsike.git` on `main`. Cloudflare automatically publishes the updated site to `https://www.vsike.com` after the push.
- After publishing, verify the changed live URLs and confirm that the new content is visible.
- Stage only files related to the requested change; unrelated local files may be present in the working tree.
